new · the phone app

On your phone, without an app store

Legato's phone app is its web app. Open your server's address in Chrome or Safari, sign in, and add it to your home screen. It keeps playing with the phone locked, answers your headphones' buttons, and lets you drag the queue into a new order.

Away from home, Tailscale gets you there without opening a port on your router, and standard quality at 160 kbps goes easy on mobile data.

Installing it as an app needs an https address. The tester guide does it in four steps with Tailscale.

the beta so far

In testers' hands

This is the first time people outside the project are installing Legato. Testers are running v0.4.0 on their own NASes and phones, against their own libraries, and what they find decides what gets fixed before a wider release.

v0.4.0 · 9 nov 2026

New since v0.2.0

  • The desktop app, for Mac, Windows and Linux. It carries its own server, plays your files gaplessly, answers media keys, and offers each update in the app.
  • Insights: who links your artists, which bands share members, and the shortest way between any two artists.
  • Edit a track's, album's or artist's tags from its details panel, with every change shown before it's written.
  • Choose an album's cover from the Cover Art Archive, Deezer or an image of your own. Nothing is written into the files.
  • Import Apple Music's playlists, play counts and ratings, with any tracks that are only in the cloud listed.
  • A multi-disc set or a compilation stays one album, and two artists' Greatest Hits stay apart.

no need to report

Known issues

  • iPhone: tapping the playing track on the lock screen can open a different home-screen web app. It's an iOS bug; open Legato from its icon.
  • Chrome and Android can leave a short gap between tracks. Gapless is Safari's and the desktop app's for now.
  • No AirPlay from the web app yet.
  • Fixing tags writes to FLAC files only, and only if you give Legato write access.
  • The desktop app isn't signed yet, so macOS and Windows warn the first time you open it. The install guide says how to get past it.

install

Install the home server beta

It's free, and it only ever reads your music. Pick where it runs. The first scan starts on its own, and you can browse and play while it does.

Synology, through Container Manager

dsm 7.2 or later · about 20 minutes

Everything happens in DSM's web interface, with no SSH needed. Legato runs as its own ordinary user, with your music mounted read-only.

  1. 1Install Container Manager from Package Center.
  2. 2Make a legato user that can read your music folder, and note its two id numbers.
  3. 3Create a project from Legato's docker-compose.yml, with those ids and your music folder's path.

Docker, on any machine

linux/amd64 · linux/arm64

Any machine with Docker, including a Raspberry Pi 4 or 5. With Legato's docker-compose.yml in an empty folder:

terminal 
$ LEGATO_MUSIC_DIR=/path/to/music docker compose up -d
$ docker compose logs | grep "setup code"

Update later with docker compose pull && docker compose up -d.

The Docker guide →

Linux, with the install script

x64 · arm64 · systemd

Installs Legato as a service for your user and starts it at boot, including on a Raspberry Pi with a 64-bit OS. It prints the setup address and code when it's done.

terminal 
$ curl -fsSL https://legato.fm/install.sh | sh -s -- --library=/path/to/music

Update later with legato update.

Read the script first →

Mac, with Homebrew

homebrew service

Runs the server as a Homebrew service.

terminal 
$ brew tap danielbchurchill/legato
$ brew trust danielbchurchill/legato
$ brew install legato
$ brew services start legato

If Homebrew says trust is an unknown command, it's older and doesn't need that line. Update later with brew upgrade legato.

then, from a computer on your network

  1. 1

    Open the setup page

    Go to http://<server>:8899/setup. On a Synology, that's your NAS's address with :8899/setup on the end.

  2. 2

    Create your account

    A name and a password. It stays on your server, works without an internet connection, and signs you in from every browser and phone.

  3. 3

    Add your music

    Choose your music folder, which is /music in Docker. Albums appear as the first scan reaches them.
